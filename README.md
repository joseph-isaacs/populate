# data-comb

A trait-based library for generating test data with composable distributions, designed for columnar data structures. Inspired by parser combinators (like nom), it provides small, focused distribution primitives that can be combined to generate complex, realistic datasets with controllable statistical properties—from simple uniform ranges to clustered runs, nullable columns, and weighted selections.
